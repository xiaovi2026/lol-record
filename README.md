# lol-record: 英雄联盟对局录像分析 (v0.4.0)

基于 **Tauri v2** 开发的轻量级英雄联盟对局录像分析工具，实现本地录像与战绩时间线（LCU Timeline）的联动分析。

---

## ✨ 核心特性

1. **官方录像联动 (配合英雄联盟“英雄时刻”)**:
   - 英雄联盟客户端自带“英雄时刻”对局完整录制功能，本项目不再重复进行底层屏幕与音频录制，从而实现极低的系统资源占用。
2. **极简主界面**:
   - 软件主界面仅保留核心要素：软件名称、版本号 (`v0.4.0`)、GitHub 链接、英雄联盟客户端连接状态卡片、支持拖拽与点击选择的文件导入框。
3. **独立对局录像分析窗口**:
   - 导入本地录像视频文件后，自动打开独立的对局录像分析窗口；
   - **左侧视频播放器**：全功能播放器（播放/暂停、倍速、全屏、音量），进度条上针对对局关键事件进行**时间戳打点标记 (Markers)**，悬浮可查看事件摘要，点击标记直接跳转；提供**时间对齐微调**功能，确保录像与游戏时间精确同步；
   - **右侧时间线事件流**：通过 LCU API 自动获取该场对局的详细时间线事件（包含击杀、多杀、中立生物：小龙/大龙/先锋/巢虫、摧毁防御塔与水晶等）；
   - **双向联动**：点击右侧任意事件，视频即刻跳转至对应时间点；视频播放过程中自动高亮追踪当前事件。

## 🛠 目录结构说明

```text
lol-record/
├── src/                        # 前端 Webview 界面
│   ├── index.html              # 主界面 (软件名称/版本/GitHub/客户端状态/拖拽文件选择)
│   ├── main.js                 # 主界面交互逻辑与 LCU 状态检查
│   ├── analysis.html           # 独立对局分析窗口 (视频播放器 + 时间线事件流)
│   ├── analysis.js             # 对局分析业务逻辑 (LCU 时间线解析/打点标记/跳转联动)
│   └── styles.css              # Hextech 科技暗色风样式表
└── src-tauri/                  # 后端 Rust Core 代码
    ├── src/
    │   ├── lib.rs              # Tauri 命令注册、状态管理与分析窗口创建
    │   └── lcu.rs              # LOL 进程检测与 LCU 凭据读取、英雄中文名对照
    ├── Cargo.toml              # Rust 依赖与 v0.4.0 版本声明
    └── tauri.conf.json         # Tauri v2 配置文件 (窗口与 assetProtocol 资源协议配置)
```

## 🚀 开发者指南

### 1. 启动开发调试
在项目根目录下运行：
```powershell
cargo tauri dev
```
项目会编译后端 Rust 代码并自动拉起主界面，支持热重载。

### 2. 打包生成 exe 安装包
```powershell
cargo tauri build
```
打包成功后，安装包会生成在 `src-tauri/target/release/bundle/nsis/` 目录下。
